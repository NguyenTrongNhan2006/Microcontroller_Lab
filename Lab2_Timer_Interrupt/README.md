# Lab 2: Timer & Interrupts

**Course**: Microcontroller / Thực tập Vi điều khiển (HCMUT - BKU)  
**Instructor**: Dr. Le Trong Nhan  

---

## 🎯 Objectives
- Understand hardware timers on STM32 (TIM2, TIM3, TIM4...).
- Configure Timer Interrupts (Update Interrupt - UIF) via STM32CubeIDE.
- Implement software timer arrays to achieve cooperative multitasking without using blocking `HAL_Delay()`.
- Re-implement LED animations and traffic light control with precise timing interrupts.
