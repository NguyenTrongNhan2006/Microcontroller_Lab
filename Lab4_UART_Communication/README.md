# Lab 4: UART Communication & Command Parser

**Course**: Microcontroller / Thực tập Vi điều khiển (HCMUT - BKU)  
**Instructor**: Dr. Le Trong Nhan  

---

## 🎯 Objectives
- Configure USART/UART peripheral in asynchronous mode (Baud rate 9600 / 115200 bps, 8N1).
- Implement UART Receive Interrupt (RXNE) with circular buffer (Ring Buffer).
- Build a serial command line interface (CLI) / communication protocol:
  - Command parsing: e.g. `!RST#`, `!OK#`
  - Timeout and retransmission handling.
