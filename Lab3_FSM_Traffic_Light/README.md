## 🎯 Objectives
- Design Finite State Machine (FSM) diagrams for embedded systems.
- Button interfacing with debounce algorithms (chống rung phím bấm) and long-press detection.
- Multi-mode traffic light controller:
  - Normal Operation Mode (Tự động theo chu kỳ)
  - Manual Adjustment Mode (Chỉnh sửa thời gian đỏ, vàng, xanh bằng nút bấm)
  - Blinky / Maintenance Mode (Chế độ nháy vàng cảnh báo ban đêm)
