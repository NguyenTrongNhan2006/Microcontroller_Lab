## 🎯 Objectives
- Configure Analog-to-Digital Converter (ADC) on STM32F103 (12-bit SAR ADC).

- Interfacing with analog sensors (Potentiometer, LM35 temperature sensor, LDR light sensor).
- Real-time PWM generation for LED brightness control / DC motor speed control.
